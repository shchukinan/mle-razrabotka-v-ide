# mle-razrabotka-v-ide

Проект для генерации отчётов по DataFrame: базовая статистика, дубликаты, пропуски, сводная статистика.

## Проблема

При работе с новыми датасетами нужно быстро получить общую картину качества данных: размерность, долю дубликатов, количество и долю пропусков, сводную статистику по признакам. Класс `DataFrameReporter` автоматизирует формирование такого отчёта и позволяет гибко настраивать формат вывода.

## Установка и запуск
Для установки необходимых библиотек выполните команду в терминале, предварительно активировав виртуальное окружение Python:

```python
pip install -r requirements.txt
```
Для формирования отчета выполните команду в терминале, находясь в корневой папке проекта:

```python
python3 main.py
```
В консоли появится отчёт с количеством строк/столбцов, количеством и долей дубликатов, сводной статистикой и информацией о пропусках (количеством и долей)git add README.md requirements.txt
